# VP Dice Roller

Una aplicación web estática para lanzar dados de Dungeons & Dragons: D4, D6, D8, D10, D12 y D20.

## Funciones

- Animación 3D de lanzamiento
- Entre 1 y 10 dados por tirada
- Modificadores de -20 a +20
- Historial persistente en el navegador
- Estadísticas diarias
- Efectos de sonido opcionales
- Diseño responsive y accesible

No requiere instalación ni proceso de build. Abre `index.html` o sirve la carpeta con cualquier servidor estático.
