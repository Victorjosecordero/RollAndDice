# VP Dice Roller

Una aplicación web estática para lanzar dados de Dungeons & Dragons sobre una mesa WebGL 3D: D4, D6, D8, D10, D12 y D20.

## Funciones

- Dados 3D reales con iluminación, sombras, rotación y rebotes
- Reservas mixtas de hasta 14 dados por tirada
- Modificadores de -30 a +30
- Historial persistente en el navegador
- Estadísticas diarias
- Efectos de sonido opcionales
- Diseño responsive y accesible

No requiere instalación ni proceso de build. Abre `index.html` o sirve la carpeta con cualquier servidor estático.
